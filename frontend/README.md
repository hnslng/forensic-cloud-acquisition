# Frontend

Eigenständige deutsche HTML/CSS/JS-Oberfläche mit Anmeldung, Fallübersicht,
Bearbeitung, Audit, Fallrechte- und Benutzerverwaltung. Gestaltung orientiert
sich an den untersuchten TRIAGE//BOX-Konzepten, ohne deren Quellmodule zu kopieren.
Benutzerdaten werden als Textknoten gerendert. Keine Tokens im Local Storage.
Cloud-Konten und Sicherungsfortschritt werden erst nach Implementierung ergänzt.
